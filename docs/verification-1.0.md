# 1.0.0 验收记录

日期：2026-10-20。环境：Windows、Node.js 24.19.0、Windows PowerShell 5.1 / .NET Framework。为减少对正在使用电脑的用户干扰，本轮集中运行后台测试；没有打开真实 Claude、切换前台、读写系统剪贴板、点击聊天控件或发送测试消息。

## 已完成检查

- `npm test`：36 项通过。包括真实 MCP stdio、鉴权回环服务、API 协议、升级默认模式、离线既有逻辑及失败处理。
- Windows 回归：通过。使用不激活、屏幕外的真实 WPF 辅助功能样例窗口，包含展开/折叠思考、正文、工具中间文本和无关 UI；没有把模拟思考当成真实 Claude 内部内容。
- 英文准备接口与独立桌面最终检查都拒绝中文，包括代码、路径和扩展区汉字；翻译失败或缺少 Key 不回退原文。
- API 的代码占位符和数值保持、截断拒绝、无效 JSON、鉴权错误、HTTPS 目标、禁止重定向与去重缓存均验证。
- 多条消息、公开思考先于最终回答翻译、流式正文等待、失败退避/刷新、切换聊天后拒绝旧结果均验证。
- 默认 API 模式不暴露旧双语工具；中文输出只显示在伴随窗口。旧 account 模式只能显式开启，0.4 默认配置升级为 API 模式。
- 生产依赖审计：0 个已知漏洞。原有 MCPB 打包开发工具中的 `node-forge` 审计提示不属于生产安装包，本次未增加生产依赖。

安装包构建使用官方 MCPB 校验器及生产依赖白名单。包内验证从独立解压目录启动真实 MCP：默认只暴露三个工具、没有旧双语提示；无 Key 时已有英文可准备，中文请求被拒绝。安装包不含本机 Key、草稿、日志或模型。发布资产提供 `SHA256SUMS.txt`，远程 CI 结果以 GitHub Actions 为准。

## 本轮没有验证的内容

**用户未提供可用于真实服务的翻译 API Key。** 云端 API 测试使用隔离响应及真实回环服务验证请求/响应、保护和错误路径；这些测试不是语言模型翻译准确率评测，也不证明特定付费账号的 Key、额度和模型可用。没有请求收费 API，没有沿用 0.4 的 Claude 双语样例冒充本次 API 翻译结果。

**没有对用户真实 Claude 会话重新发送消息或操作思考控件。** 输出读取适配以已知正文类名、语义展开控件、思考/中间区块标识及隐藏窗口测试为依据。真实 Claude 版本若改变这些辅助功能结构，可能需要继续适配。与服务端不公开的内部思考、图像、未加载历史无关；插件不会声称能读取这些内容。

0.4 的真实账号双语验收仅是历史记录，见 [历史验收](verification.md)；离线模型的既有语义样例见 [翻译质量报告](translation-quality.md)。

## 用户验收步骤

1. 安装 GitHub Release 的 `claude-desktop-translator-1.0.0.mcpb`。本轮没有为测试而启动 Claude 或替换用户正在使用的桌面窗口，旧版仍需自行升级。
2. 在扩展设置填写翻译 API Key、服务商 HTTPS 基础地址及模型，保持离线、旧双语开关关闭。确认标题为 `API 英文提交 · v1.0.0`。
3. 输入：`只有测试通过且耗时不超过 250 毫秒才能继续；不要执行代码、删除文件或上传数据。请解释这些限制。`。核对英文预览包含全部条件和三个禁止事项；Claude 用户消息应不含中文。
4. 再输入含中文字符串或中文路径的代码，确认停止提交并保留草稿。
5. 当 Claude 展示公开思考时手动展开，点击伴随窗口“刷新”。核对思考与回答分别出现中文；未公开内容应只给出无法读取的提示，不捏造思考。
6. 保留两条以上回答，确认逐条显示；切换聊天，确认旧翻译不会覆盖新会话。翻译失败可点刷新重试。

默认 DeepSeek 配置来自 [官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。Key 的敏感字段来自 [MCPB 规范](https://github.com/modelcontextprotocol/mcpb/blob/main/MANIFEST.md#user-configuration)。不含中文的输入不能保证避免账号封禁。
