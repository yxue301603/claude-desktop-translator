# 1.0 插件使用说明

## 默认：API 先翻译，Claude 只接收英文

在 Claude 扩展设置中填入翻译服务的 API Key、基础地址和模型。默认使用 DeepSeek 官方 `https://api.deepseek.com` 与 `deepseek-flash`；也支持其他兼容 `/chat/completions` 的 HTTPS 地址。Key 用于翻译，不是 Claude 登录令牌，也不会改变主对话登录方式。协议见 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

安装 `claude-desktop-translator-1.0.0.mcpb` 后，关闭“使用本地离线翻译”和“允许发送中文：使用旧账号双语模式”，重新启用扩展。在 `API 英文提交 · v1.0.0` 窗口输入中文，Enter 发送；Shift+Enter 换行。窗口关闭后可重新启用扩展，或调用 `open_translation_window` 重新打开。

缺少 Key 时，中文不会提交；已有英文可直接准备提交。翻译后仍含中文（包括代码和路径中的中文）也会停止，不会自动换成旧模式。配置变更后重新启用扩展，避免沿用旧进程；更改服务商、模型或 Key 会重新建立相应的本地翻译服务。

这里只保证本工具的提交路径，不会修改 Claude 原生输入框行为，不拦截手动发送、附件或其他插件。换成英文不能保证避免封号。

## 输出时间线

开启“自动翻译各条输出和已展开的思考”，将按消息显示各个可读取区块。支持回答正文、公开思考区域，以及可识别的工具/中间文本；按钮、隐藏首句摘要和推广控件不作为正文翻译。完整正文不可用时重试，不能用首句摘要代替。

思考被折叠时，请在 Claude 中手动展开，再点伴随窗口“刷新”。不会自动点击、展开、滚动或抢占你的窗口。没有通过辅助功能暴露的内部思考、未加载历史、图片和二进制工具结果不支持；不能从思考标题还原未公开正文。

生成中的最终回答先等待，稳定的公开思考可以先译。每个区块单独去重与缓存；已存在的旧消息也会处理，后续增长只刷新相应区块。切换会话后，旧请求的迟到结果不会覆盖当前译文。失败后退避 30 秒，点“刷新”可立即重试。API 模式下，当前辅助功能暴露的待译历史也会发给所选服务商并可能计费；关闭自动翻译可停止后续读取翻译。

## 保留模式

- 打开“使用本地离线翻译”：需要已安装的 Ollama 和 Hy-MT2。输入仍需通过不含中文的最终校验；输出时间线相同。
- 打开“允许发送中文：使用旧账号双语模式”：明确允许把中文原文发给当前 Claude，继续 0.4 的三段式双语回答。此模式不满足英文提交要求，也不能独立翻译思考或普通英文回答。
- 两项均开启会报错，不会自行决定使用哪一个。

## 权限与草稿

MCPB 提供伴随窗口及工具，不修改 Claude 安装文件。使用 Windows 辅助功能读取当前聊天，发送需要桌面未锁定、目标窗口获得真实前台焦点、Claude 没有其他草稿且内容校验一致。只在你点击发送或按 Enter 后提交，没有全局键鼠监听。

会临时粘贴并恢复剪贴板；期间新的用户复制优先保留。未发送输入使用 Windows DPAPI 加密保存，下次恢复，发送成功或清空后删除。本机令牌、模式和加密草稿位于 `%USERPROFILE%/.claude-desktop-translator/`；API Key 不保存到该目录。主程序正常日志不记录聊天文本或 Key。更多见 [数据处理](privacy.md)。

普通 Chat 的官方扩展没有全局输入/输出 Hook，因此仍需伴随窗口；参见 [Claude 插件能力](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)。敏感 Key 字段使用 [官方 MCPB 配置机制](https://github.com/modelcontextprotocol/mcpb/blob/main/MANIFEST.md#user-configuration)。
