# 数据处理说明

本扩展由 yxue301603 的开源项目提供，与 Anthropic 或翻译服务商无隶属关系。

- 默认 `api` 模式把中文请求，以及辅助功能暴露的待译回答、思考摘要、中间文本交给**用户配置的翻译服务商**。服务商会收到这些内容，并按自己的隐私政策与计费规则处理。默认地址为 DeepSeek 官方接口，可由用户更改。
- 校验通过的英文由用户当前登录的 Claude 官方桌面应用发送。主对话遵循 [Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)。本项目没有远程接收服务器、主模型 Gateway 或遥测。
- `offline` 模式只向本机 `127.0.0.1:11434` 的 Ollama 发送翻译请求；权重首次下载需要联网。输入仍校验不含中文。
- 旧 `account` 模式需用户明确选择，**会将中文原文发给 Claude**。它不经过翻译 API，也不能独立回译思考。
- API Key 通过 MCPB 的敏感字段由 Claude 管理，以进程环境变量传入翻译服务；本项目不把它写入配置、日志、安装包、GitHub 或伴随窗口子进程。HTTPS API 请求拒绝重定向，不展示可能回显私密信息的服务端错误正文。
- 回环服务使用随机本机令牌并拒绝网页 Origin，仅监听 `127.0.0.1`。不读取、导出或复用 Claude 的 OAuth 登录凭据。
- 通过辅助功能读取当前聊天。不注册全局键鼠监听，不自动展开思考或滚动，不恢复未公开内部思考。发送由用户主动操作触发；锁屏或目标未取得前台焦点时停止。
- 临时使用剪贴板粘贴消息并恢复；期间用户新复制的内容优先保留。系统剪贴板历史及同步由系统设置决定。
- 未发送输入以 Windows 当前用户 DPAPI 加密保存在本机 `companion-draft.bin`。发送成功或清空后删除。文本翻译缓存与输出时间线只驻留进程内存，正常日志不记录原文与译文。

本机数据目录为 `%USERPROFILE%/.claude-desktop-translator/`。卸载后已有模型、配置及未发送草稿保留；如需清理，请先保存需要的草稿，再自行删除。API Key 请在 Claude 扩展设置或对应环境变量中移除。
