# 数据处理说明

本扩展由 yxue301603 的开源项目提供，与 Anthropic 无隶属关系。

- `account` 模式将中文原文和英文流程指令一起提交至用户当前登录的 Claude 官方桌面会话，使用现有聊天额度。主对话的数据处理遵循 [Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)。本项目不提供远程翻译服务器，不接收这些文本。
- `offline` 模式将待翻译文本发送给本机 `127.0.0.1:11434` 的 Ollama。翻译后的英文由 Claude 官方桌面应用发送。模型首次下载需联网，权重不随本扩展分发。
- 扩展的伴随服务仅监听回环地址，使用随机本机令牌；拒绝带网页 Origin 的请求。
- 不读取、导出或直接复用 Claude 登录凭据，不使用第三方 Gateway、翻译 API 或遥测。
- 发送由用户点击或按 Enter 触发。伴随窗口通过 Windows 辅助功能读取当前 Claude 输入框和回答，不注册全局键鼠监听，不修改 Claude 界面。
- 临时使用剪贴板粘贴完整消息，并在校验后恢复；用户在此期间新复制的内容优先保留。Windows 剪贴板历史和同步由用户系统设置控制。
- 本机配置位于 `%USERPROFILE%/.claude-desktop-translator/`，包含回环服务令牌与模式设置。正常日志只含启动阶段和错误，不含原文或回答。
- 未发送输入使用 Windows 当前用户的 DPAPI 加密保存为 `companion-draft.bin`，重新打开窗口时恢复；发送成功或清空输入后删除。该文件不上传 GitHub，不包含在安装包中。

卸载扩展会停止 Claude 管理的 MCP 进程。已有模型、用户配置和未发送草稿不会被扩展主动删除；需要清理时，请先保存需要保留的输入，再自行删除上述本机数据目录。
